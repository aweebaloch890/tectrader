
# Tec Trader Valorant Tournament Season 2

## Features
- Valorant styled esports design
- Login / Register System
- Team Management
- Tournament Management
- Match & Veto System
- Admin Dashboard
- Responsive UI
- PWA Ready Structure

## Setup

1. Extract files inside htdocs or hosting public_html
2. Import `database.sql` in phpMyAdmin
3. Edit `config.php` if needed
4. Start Apache + MySQL
5. Open website in browser

## Default Theme
Dark Black + Gold + Red esports style.
